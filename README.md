# 🚦 TrafficIQ – AI-Based Adaptive Traffic Signal Optimization

TrafficIQ is a Machine Learning-based traffic management application designed to optimize traffic signal timings according to traffic conditions. It provides an interactive four-way intersection simulation and compares fixed-time traffic signals with adaptive signal control.

## ✨ Features

* 🚗 Interactive four-way traffic intersection simulation
* 🤖 Machine Learning-based traffic prediction using Random Forest
* 🚦 Adaptive traffic signal timing optimization
* 📊 Traffic analytics and interactive visualizations
* 🔄 Dynamic vehicle controls for North, South, East, and West
* 📈 Comparison of fixed-time and adaptive traffic signal strategies
* 🛣️ Traffic scenario simulation and queue monitoring
* 🌐 Interactive web interface built with Streamlit

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd TrafficIQ
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to access TrafficIQ.
